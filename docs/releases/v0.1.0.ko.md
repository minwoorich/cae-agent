# CAE Agent v0.1.0 릴리스 노트 초안

> 이 문서는 GitHub Release 발행 전에 검토하는 초안입니다. 이 문서를
> 추가하는 PR을 병합해도 Git 태그, GitHub Release 또는 PyPI 배포가
> 자동으로 생성되지 않습니다.

CAE Agent v0.1.0은 Codex CLI가 작성한 Python 스크립트를 검토 가능한
파일로 보존하고, Ansys Workbench 안의 SpaceClaim과 Mechanical에서
실행할 수 있게 하는 첫 공개 알파 버전입니다.

## 주요 기능

- `cae-agent doctor`로 Python, Codex CLI, Ansys와 작업공간 상태 진단
- Workbench 세션과 Steady-State Thermal 프로젝트 생성·관리
- SpaceClaim 및 Mechanical 스크립트의 명시적 실행
- Codex CLI를 이용한 대상별 스크립트 생성
- 실패 traceback을 바탕으로 한 횟수 제한 자동 수정
- 전력반도체 열해석 공식 예제와 V261 기준 결과 스키마
- Windows 설치 스크립트, 다중 Python 버전 CI와 한국어 사용자 문서
- 원본·결과 보존과 기본 dry-run을 적용한 작업공간 용량 조회 및 정리
- localhost에서만 실행되는 선택형 상태·정리 승인 대시보드
- 허용 형식과 크기를 서버에서 검증하는 CAE 입력 파일 업로드
- 작업 순서와 상태를 명확히 구분하는 엔지니어링 대시보드 정보 구조

## 지원 환경

- 운영체제: Windows
- Python: 3.11, 3.12, 3.13, 3.14
- 최초 검증 Ansys 버전: Ansys Student 2026 R1(V261)
- 최초 AI 제공자: 로컬에서 로그인한 Codex CLI

Ansys 또는 Codex가 없어도 기본 패키지와 일부 명령은 사용할 수 있지만,
각 구성요소가 담당하는 자동화 기능은 실행할 수 없습니다. 자세한 준비
절차는 [한국어 시작 가이드](../getting-started.ko.md)를 참고하세요.

## 중요한 안전 안내

- AI 생성 스크립트를 실행하기 전에 내용을 검토하세요.
- `run-agent`는 `--approve-execution`을 명시해야만 생성 코드를 실행합니다.
- 기존 형상 삭제가 가능한 `--clear`와 파일 교체가 가능한 `--overwrite`는
  대상과 백업을 확인한 뒤 사용하세요.
- GitHub Issue에 토큰, 사용자 절대경로, 비공개 CAD, 라이선스 정보를
  첨부하지 마세요.

## 알려진 제한

- macOS와 Linux는 공식 지원하지 않습니다.
- Claude Code 제공자는 아직 구현하지 않았습니다.
- 여러 Workbench 시스템의 병렬 자율 제어는 지원하지 않습니다.
- GitHub Actions에서는 Ansys 라이선스가 필요한 통합 테스트를 실행하지 않습니다.
- 자동 수정은 제한된 재시도 도구이며 해석 결과의 공학적 타당성을 보증하지 않습니다.
